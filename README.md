# 秋を旅する。｜2026 九州紅葉・溫泉自駕手帖

一個適合手機使用、日系文青風格的繁體中文旅行網站。

**行程日期：2026年11月12日至18日（7日6晚）**

路線：福岡 → 門司港 → 唐戶市場 → 耶馬溪 → 別府 → 由布院 → 九重 → 黑川溫泉 → 阿蘇 → 柳川（元祖本吉屋鰻魚飯）→ 福岡國際機場。

## 網站功能

- 單頁響應式設計：手機、平板、桌面都可用
- 和紙色系、日本字體、紅葉裝飾、滑動進場動畫；支援減少動態效果設定
- 每天行程、預計時間、推薦住宿地區、行車時間
- 每個景點及餐廳都有 **Google Maps 駕駛導航** 連結
- 按天「查看整日路線」快捷連結
- 柳川 **元祖本吉屋** 鰻魚飯重點介紹、電話、預約說明與導航
- 福岡機場國際線附近租車營業所還車導航
- 可分享網站網址、行程完成打勾與出發前檢查清單（僅儲存在瀏覽器）
- 真實景點圖片及圖片作者／來源連結（Wikimedia Commons）

## 啟用 GitHub Pages（一次性）

1. 打開本 repository 的 **Settings**。
2. 左邊選 **Pages**。
3. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
4. **Branch** 選 `main`，資料夾選 `/(root)`，按 **Save**。
5. 等 GitHub 完成發佈，再開啟：

   **https://kinleong-partyhome.github.io/fukuoka-trip/**

網站直接放在根目錄 `index.html`，不需要 npm、Vite、React 或任何 build 流程。

> 如果 Pages 未啟用，GitHub repository 只會顯示程式碼，不能當作公開旅行網站分享。網站圖片使用 Wikimedia Commons 外部連結，開啟時需要網路。

## 編輯內容

行程、時間、Google Maps 搜尋地址、圖片都在 `index.html` 最下方的 `days`、`photos` 變數，可以直接在 GitHub 編輯並 commit；已啟用 Pages 時會自動更新。

## 重要提醒

本網站是旅遊規劃，不代表已訂餐廳、酒店或租車；車程、營業時間、票價、路況、紅葉時間，請出發前再次確認。元祖本吉屋本店一般星期一公休，星期二通常營業，電話預約：**0944-72-6155**（是否有位需自行確認）。租車公司只是提供國際線營業所的實用例子，實際請依租車確認書。

航班資訊按照旅行者提供之截圖整理，若航班、航廈或時間有更改，請以航空公司最新通知為準。

圖片來源及作者的連結可在網站底部「圖片來源及授權」展開查看；其中柳川鰻魚飯照片拍攝於**若松屋**，僅用於柳川蒸籠鰻魚飯類型示意，**不是**元祖本吉屋實拍或餐點。
